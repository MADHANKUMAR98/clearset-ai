# Skill: `determine_root_cause`

## Execution Steps
1. Isolate primary operational failure (e.g. missing standing instruction, cash mismatch, depository hold).
2. Identify contributing factors (counterparty historical delays, upcoming cutoff deadline, transaction volume peak).
3. Produce transparent explanation distinguishing immediate symptoms from core institutional causes.
